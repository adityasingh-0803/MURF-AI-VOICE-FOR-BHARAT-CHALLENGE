---

## 🚀 Overview

ShikshaSaathi is a voice-first AI tutor designed to help students learn through natural conversations.

The goal is to make education more interactive and accessible by combining real-time voice interactions with AI.

This project uses **Murf Falcon**, the fastest Text-to-Speech API, to provide natural Indian voices.
